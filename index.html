🏳 TicketTriage — Support Ticket Priority Classifier

A 2nd-year B.Tech AI/ML project by Vikranth Reddy. A TF-IDF + multinomial logistic regression model trained on 200 hand-written support tickets (50 each of critical, high, medium and low priority; 685 words) predicts how urgent a ticket is. 5-fold CV: accuracy = 74.5% vs a majority-class baseline of 25.0%.

How it works: the ticket is split into words, each word gets a TF-IDF weight (common words count less, rare words count more), the weights are multiplied by the model's learned coefficients for each of the four priorities, and a softmax turns the four scores into percentages. The exact same weights run in this page and in the Python training script (train.py), so the browser result matches the trained model.

Try it: “The entire website is down and no customer can log in at all” → critical, about 72.4%. “Many users cannot log in since the morning update and get an error” → high, about 57.7%. “There is a small spelling mistake in the welcome message on the home page” → low, about 51.3%. A plain sentence with no ticket words, like “The quarterly sales report was shared with the team on Tuesday”, scores low and flat across all four — the model honestly says it cannot tell.
